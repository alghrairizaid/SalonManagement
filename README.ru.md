# FreelanceShield - Система управления маникюрным салоном

## Технические требования
- Node.js 18+
- SQLite3
- npm или yarn

## Особенности
- Многоуровневая система аутентификации (администратор, мастер, клиент)
- Управление записями и бронированиями
- Управление услугами и ценами
- Панель управления администратора
- Панель управления мастера
- Панель управления клиента
- Система оценки услуг
- Система уведомлений
- Удобный пользовательский интерфейс
- Поддержка русского языка

## Установка
1. Установите Node.js
2. Скачайте проект
3. Установите зависимости:
```bash
npm install
```
4. Запустите сервер:
```bash
npm start
```

## Структура проекта
- `config/` - файлы конфигурации
- `controllers/` - контроллеры
- `middleware/` - промежуточное ПО
- `models/` - модели
- `public/` - статические файлы
- `routes/` - маршруты
- `views/` - шаблоны
- `app.js` - точка входа
